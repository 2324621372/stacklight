# 叠光记 · Stacklight

依照桌面上的《叠光记-游戏设计文档》和文案表制作的竖屏浏览器游戏。纯静态资源，手机与电脑可运行，无需后端或运行时第三方依赖。

## 本地运行

需要 Node.js 22 或更新版本，在本目录运行 `npm start`，打开 http://localhost:4173 。同一局域网的设备也可通过本机局域网 IP 的 4173 端口访问（需要系统防火墙放行）。请通过 HTTP 服务运行，不要直接双击 HTML。

`npm install` 安装浏览器测试依赖；`npm test` 运行核心规则测试；安装 Microsoft Edge 后，启动本地服务并运行 `npm run test:browser` 完成浏览器验证。

## 操作与规则

- 电脑：← → 移动，空格或 ↓ 落下，P / Esc 暂停，E 使用道具。
- 手机：左右拖动移动，轻点画布落下，或用下方按钮操作。拖动松开只调整位置。
- 每块 4.5 秒自动落下；缓落羽令下一块下落持续 3 秒。
- 采用设计文档允许的层叠简化结构：上下相邻且重叠的同色两层消除，消除后再次检查连锁。连续落块触发消除会累计连光，图鉴「连光」要求连续 5 次。
- 30 层为危险线，失衡达 100% 结束。高度统计记录本局到达的最高层数；默认数值在 engine.js 的 CONFIG 中配置。
- 风暴首次 45 秒，间隔逐渐缩短；横风与黑暗交替，横风持续 6 秒，黑暗持续 2 秒；每轮消除延后风暴 2 秒。
- 每日挑战按本地日期固定种子：双色到达 25 层、提前风暴撑过 3 次、禁道具达到 1500 分。跨日重进刷新，同一天可以反复挑战。
- 本地保存纪录、设置、图鉴与每日进度。不同浏览器和设备之间不自动同步；清除网站数据也会清除存档。
- 音乐和音效通过 Web Audio 合成，需要首次用户交互后播放。振动取决于浏览器支持。支持系统减少动态效果设置。

## GitHub Pages

仓库默认分支为 main，Pages 的 Source 设置为 GitHub Actions。推送后 `.github/workflows/pages.yml` 先运行规则测试，再发布页面资源。使用相对资源路径，支持仓库子路径。

分享按钮优先使用系统分享，不支持时复制成绩和链接。没有联网排行榜、广告或服务端。
