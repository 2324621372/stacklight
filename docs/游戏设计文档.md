# 叠光记（Stacklight）游戏设计文档

| 项目 | 内容 |
|------|------|
| 文档版本 | v1.0 |
| 更新日期 | 2026-10-20 |
| 游戏类型 | 单机休闲 / 竖屏 / 一局制 |
| 目标体量 | 中等（约 1–2 周可出可玩版） |
| 一局时长 | 2–4 分钟 |
| 目标平台 | 手机 / 网页（竖屏优先） |

---

## 1. 概述

### 1.1 一句话介绍

在限定节奏下把「光块」叠成塔：对齐得分、同色相连可消，撑过风暴、稳住失衡，冲击本局最高光分。

### 1.2 核心体验

- **上手快**：左右移动 + 点击落下。
- **有策略**：颜色规划、是否主动消层、风暴前预留空间。
- **有紧张感**：失衡条 + 周期性风暴，逼玩家在「冲高」和「稳住」之间取舍。

### 1.3 非目标（本期不做）

- 联网对战、排行榜服务器
- 重度养成 / RPG 数值
- 复杂物理刚体（可用简化对齐判定代替真实物理）

## 2. 核心玩法

### 2.1 基础循环

1. 上方生成一块带**颜色**的光块。
2. 玩家左右移动，点击（或松开）使其落下。
3. 落地后结算：对齐分、高度分、同色消除、失衡变化。
4. 生成下一块；周期性触发风暴。
5. 触顶或失衡条满 → 本局结束 → 结算页。

### 2.2 操作

| 输入 | 行为 |
|------|------|
| 左 / 右（滑动或按键） | 水平移动当前光块 |
| 点击 / 空格 / 下落键 | 立即落下 |
| 暂停按钮 | 打开暂停菜单 |

移动步进建议：以「半格」或「连续平滑」二选一；首版推荐**网格吸附**，降低实现成本。

### 2.3 颜色与消除

- 颜色种类：**4 色**（青 / 金 / 玫 / 白）。
- 落地后：与**正下方或左右相邻**的同色块形成连接组。
- 连接数 ≥ 2 时消除（建议规则：至少 2 块同色相连即消；若实现简单可改为「与正下方同色则消一层」）。
- **连消**：一次落地触发的连续消除计为连消，最高展示到 3+。
- 消除后上方块下落填补（若使用层叠结构），再检测是否继续消除。

### 2.4 对齐与失衡

- 每块有「理想落点」（相对塔顶中心或上一块中心）。
- 偏离超过阈值（如半格宽度）→ **失衡值增加**。
- 连续较准对齐 → 失衡值缓慢回落。
- 失衡条满 → 失败（文案：重心散了，光也散了）。

### 2.5 高度与危险线

- 塔高以「层」计。
- 屏幕上方有**危险线**；塔顶触及危险线 → 失败（文案：太高了，也太险了）。
- 消除可降低塔高，是续命手段。

### 2.6 风暴系统

| 项目 | 规则 |
|------|------|
| 首次间隔 | 约 45 秒 |
| 之后每次 | 间隔缩短 5 秒，最短 20 秒 |
| 类型 A：横风 | 落点随机左右偏移（或移动输入被扰动） |
| 类型 B：黑暗 | 2 秒内隐藏颜色（只显示轮廓） |
| 预警 | 风暴前 3 秒 UI 提示「风暴将至…」 |
| 失败相关 | 风暴本身不直接秒杀；风暴中失误导致失衡/触顶 |

连消可**延迟下次风暴**（如每次有效连消 +2 秒）。

### 2.7 胜负与目标

- **无传统通关**：以单局高分、高度、撑过风暴次数为成就。
- 软目标示例：撑过第 N 次风暴、达到 25/50 层。

## 3. 数值设计

### 3.1 计分

| 事件 | 分数 |
|------|------|
| 成功落地 | +10 |
| 每层高度奖励 | +2 × 当前层数（或仅对新一层 +2） |
| 2 连消 | 倍率 ×1.5（对该次消除基础分） |
| 3 连消 | 倍率 ×2.5 |
| 3 连消额外 | 下次风暴延迟 +2 秒 |

**光分** = 本局累计总分，用于纪录与结算展示。

### 3.2 手感目标

| 玩家 | 预期结束层数 |
|------|----------------|
| 新手 | 20–40 层 |
| 熟练 | 50+ 层 |

### 3.3 道具（局内）

开局可携带 1 个，或局中稀有掉落（首版建议：开局三选一）。

| ID | 名称 | 效果 | 描述文案 |
|----|------|------|----------|
| `steady` | 稳心石 | 立刻清空失衡条 | 立刻清空失衡条 |
| `clear_dark` | 破暗镜 | 下一次黑暗风暴无效 | 下次黑暗风暴无效 |
| `slow_fall` | 缓落羽 | 下一块下落变慢，持续 3 秒 | 下一块下落变慢 3 秒 |

获得提示：`获得「%s」——用在最晃的那一刻。`

### 3.4 可调参数（建议做成配置表）

```text
colors: [cyan, gold, rose, white]
base_land_score: 10
height_bonus_per_layer: 2
combo_2_multiplier: 1.5
combo_3_multiplier: 2.5
storm_first_delay_sec: 45
storm_min_interval_sec: 20
storm_interval_shrink_sec: 5
storm_dark_duration_sec: 2
storm_warn_sec: 3
imbalance_fail_threshold: 100
imbalance_recover_per_good_land: 8
imbalance_add_per_bad_land: 15
```

## 4. 模式与系统

### 4.1 经典模式

无限一局，直到失败；记录本地最高光分、最高层数、最多撑过风暴次数。

### 4.2 每日挑战

- 入口文案：今日光题
- 每日固定种子 + 一条规则（本地按日期生成即可）。
- 规则池示例：
  1. 只有蓝与金两种色，叠到 25 层
  2. 风暴提前 30%，撑过 3 次
  3. 禁止使用道具，冲击高分
- 完成：今日课题已点亮
- 未完成再次进入：显示进度；跨天后刷新

### 4.3 图鉴（轻成长）

解锁条件示例：

| 图鉴 ID | 名称 | 条件 |
|---------|------|------|
| `first_run` | 初光 | 完成第一局 |
| `against_wind` | 逆风者 | 风暴中成功落下 10 块 |
| `stable_master` | 稳塔师 | 单局失衡从未超过 50% 且撑过 3 次风暴 |
| `storm_1` / `3` / `5` | 分级风暴称号 | 累计撑过 1/3/5 次风暴（生涯或单局按产品定） |
| `combo_10` | 连光 | 单局最高连消达到 10（若连消定义较严可改为 5） |

奖励：解锁塔皮肤 / 背景（纯表现，不影响数值）。

### 4.4 本地存档

- 最高光分、最高层、教程是否完成、图鉴解锁、设置项、每日挑战日期与完成状态。

## 5. 界面与文案

### 5.1 主界面

| 元素 | 文案 |
|------|------|
| 标题 | 叠光记 |
| 副标题 | 稳住光，叠到天边 |
| 按钮 | 开始游戏 |
| 按钮 | 每日挑战 |

| 按钮 | 设置 |
| 空纪录 | 还没有最高纪录，来叠第一座光塔吧 |

### 5.2 教程（3 步，可跳过）

1. **移动与落下**  
   左右调整位置，点击屏幕让光块落下。
2. **同色相连**  
   同色相邻会消掉一层，消得越多，风暴越晚来。
3. **注意失衡**  
   塔歪了会晃。稳住重心，比单纯冲高更重要。

### 5.3 局内 HUD

| 元素 | 文案格式 |
|------|----------|
| 分数 | 光分 %d |
| 高度 | %d 层 |
| 连消 | ×%d 连光 |
| 失衡 | 重心偏移（旁注） |
| 风暴预警 | 风暴将至… |
| 风暴中 | 风暴中！抓住节奏 |
| 暂停菜单 | 暂停 / 继续 / 放弃本局 |

### 5.4 结算

**标题（按表现档位）**

| 档位 | 条件建议 | 标题 |
|------|----------|------|
| 普通 | 默认 | 光塔熄灭了 |
| 不错 | 光分进本机前 50% 或层数 ≥ 25 | 这座塔，记得你 |
| 很好 | 撑过风暴 ≥ 3 或层数 ≥ 40 | 风暴也没吹倒你 |
| 极佳 | 新纪录或层数 ≥ 50 | 今夜最亮的一座 |

**数据行**：高度 / 最高连消 / 撑过风暴次数 / 本局光分  

**按钮**：再来一局 / 分享成绩 / 回主页  

**新纪录**：新纪录！光分 %d

### 5.5 失败原因

| 原因 | 文案 |

## 6. 美术与音频

### 6.1 视觉

- 竖屏夜空；光块半透明、自发光。
- 背景随高度变化：
  - 低：近地雾紫
  - 中：高空深蓝
  - 近危险线：稀薄晨光
- 风格关键词：安静、发光、克制，避免重度 UI 花哨特效堆叠。

### 6.2 音频

| 事件 | 建议 |
|------|------|
| 落下 | 短促「叮」 |
| 连消 | 上行琶音 |
| 风暴 | 低风声 bed |
| BGM | 轻氛围循环，风暴时加一层垫音 |

## 7. 技术实现建议

### 7.1 场景结构

```text
Boot
 └─ MainMenu
     ├─ Game (Classic)
     ├─ DailyChallenge
     ├─ Gallery
     ├─ Settings
     └─ Result (可由 Game 压栈弹出)
```

### 7.2 推荐模块

| 模块 | 职责 |
|------|------|
| `GameController` | 局内状态机：Ready / Playing / Storm / Paused / Result |
| `Board` / `Tower` | 层数据、落点、消除、高度 |
| `BlockSpawner` | 颜色随机、下一块预览 |
| `ImbalanceSystem` | 失衡增减与失败判定 |
| `StormSystem` | 计时、类型、预警、效果 |
| `ScoreSystem` | 计分与连消 |
| `ItemSystem` | 道具持有与释放 |
| `SaveService` | 本地存档 |
| `UI*Presenter` | HUD / 结算 / 教程文案绑定 |

### 7.3 局内状态机（简图）

```text
[Ready] → [Playing] ⇄ [Paused]
              ↓
          [Storm]（Playing 的子状态或叠加状态）
              ↓
          [Result]
```

## 8. 开发里程碑

### M1 — 可玩原型（约 2–3 天）

- [ ] 光块生成、左右移动、落下
- [ ] 叠高与触顶结束
- [ ] 基础落地分 + 高度分
- [ ] 简单结算（分数 / 层数）

### M2 — 中核（约 3–4 天）

- [ ] 同色消除与连消
- [ ] 失衡条与失败
- [ ] 完整结算文案与档位标题
- [ ] 暂停 / 再来一局

### M3 — 完整休闲向（约 3–5 天）

- [ ] 风暴（横风 + 黑暗）
- [ ] 3 种道具
- [ ] 每日挑战（本地日期规则）
- [ ] 本地最高分存档

### M4 — 抛光（约 2–3 天）

- [ ] 三步教程
- [ ] 图鉴与简单皮肤
- [ ] 音效 / BGM / 振动
- [ ] 分享成绩图（可选）

## 9. 验收标准（MVP）

1. 新玩家 30 秒内不看说明能完成第一次落下。
2. 一局中能稳定触发：对齐、消除、失衡警告、至少一次风暴。
3. 失败后结算信息完整，且最高分能本地保留。
4. 竖屏 16:9 / 19.5:9 下 HUD 不遮挡落点操作区。

## 10. 风险与决策备忘

| 风险 | 缓解 |
|------|------|
| 真实物理叠高难调 | 首版用网格对齐 + 偏移百分比模拟失衡 |
| 消除导致「冲高」变难 | 用连消延迟风暴、消层降危险线压力平衡 |
| 文案过长 | 局内提示不超过一行 |
| 范围膨胀 | 严格按 M1→M4，对战与服务器不做 |
